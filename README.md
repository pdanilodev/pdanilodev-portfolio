## Instalação

Clone o projeto:

```bash
git clone https://github.com/SEU-USUARIO/everton-portfolio.git
```

Entre na pasta:

```bash
cd everton-portfolio
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npm run dev
```

---

## Build de Produção

```bash
npm run build
```
